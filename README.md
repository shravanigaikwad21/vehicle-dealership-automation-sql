# 🚗 Vehicle Dealership Automation - MySQL

A complete MySQL-based Dealership Management System for Inventory, Sales & Service with low-stock alerts.

### ✨ Features
- Vehicle Inventory Management
- Sales & Customer Management
- Service Tracking
- Low-Stock Alerts using Triggers
- Business Queries for Reports

### 📂 Files
- `schema.sql` - Table structures
- `data.sql` - Sample data
- `business_queries.sql` - Reports & Alerts

### 🚀 How to Run
1. Create database: `CREATE DATABASE dealership;`
2. Import `schema.sql`
3. Import `data.sql`
4. Run queries from `business_queries.sql`
